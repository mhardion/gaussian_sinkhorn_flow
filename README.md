Numerical illustrations for the article "The Wasserstein gradient flow of the Sinkhorn divergence between Gaussian distributions" ([HAL](https://hal.science/hal-05503160v1/), [arXiv](https://arxiv.org/abs/2602.10726)).

Requirements: working versions of ```pytorch```, ```numpy```, ```matplotlib```, ```geomloss```, ```sklearn``` and ```scipy```.
